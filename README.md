# pre-research · 预调研螺旋四站法

## 它解决什么问题

对一个陌生研究主题做预调研，常见两种死法：

1. **线性瀑布**：广度调研一路铺开 → 深度调研 → 报告。没有收敛机制，面板越铺越大，或者早早锚定在第一印象的学科上。
2. **浮于表面**：按学科目录铺 60 门，每门摘两句综述——被评审为"没找到真问题"（本方法论的原始判例就是这么来的）。

这个技能（skill）把预调研变成**螺旋**：每轮"广度 → 小实验 → 深度 → 小实验 → 站 5 锁定件"，锁定件预注册下一轮面板（收敛供给 × 实验存活 × 野卡 ≥20%），循环收窄直至前沿；终止判据触发即收卷出综述。

## 螺旋四站法

```
C-k 轮：站1 广度调研（≥60 学科，按同构问题选取，禁按目录铺）
          ↓
        站2 小实验验证（五判据：预注册/沙盒/≤1会话/三态/kill criteria）
          ↓
        站3 深度调研（深度棘轮：摘要级→全文精读→方法论级）
          ↓
        站4 小实验验证
          ↓
        站5 拟定新面板锁定件 ——零锁定不开下一轮（强制回边）
```

配套机制：

- **元问题四候选淘汰**——时序内嵌优先、一问覆盖四问优先、静态二分淘汰、与既往调研撞车淘汰；选定后操作化为**证书组**（缺任一证书=一种退化形态）。
- **第一性原理推导链**——公理（只能是既有工程事实，禁凭空）→ FP（可独立证伪 + 本地器械对映，悬空思辨删除）→ 轴（每轴带同构问题，是选学科的唯一标准）。
- **时新棘轮**：轮 1 不限年代 → 逐轮推 ≥2005 / ≥2018 / ≥2024（按领域校准），防把陈年结论当前沿。
- **失速自检**：连续两站零证伪且零新收敛 → 强制红队轮（对抗性检索+实验）。

## 它有什么不一样

- **田野第六路**：文献之外，把"同行实建系统"当自然实验摸底——双源互证（设计文档+真实工件计数），README 营销文案不入证据；**化石样本强制 ≥4**（已死/停维护系统，防幸存者偏差）。
- **假引用零容忍**：每条机制带一手锚（作者·年份·题名·出处），核不到的成分标【未核】+疑点一句——原始判例实抓误引 6 处、错 DOI 4 处之后立的规矩。
- **大区审计**：按知识体系区划逐区过（教育/质量工程/安全工程等非显学区最易整片漏检——判例：按文献分布自查漏 12 门），已知偏差如实登记不掩饰。
- **零越权**：计划书候批、实验打沙盒接触面零生产写、产物落盘候批。

## 快速开始

```bash
git clone https://github.com/master666-max/pre-research.git
# 作为技能装进你的 AI 助手技能目录（以 ZCode/CodeBuddy 为例）
cp -r pre-research ~/.zcode/skills/pre-research
# Claude Code 用户
cp -r pre-research ~/.claude/skills/pre-research
```

装好后对你的助手说：

> 对「XXX」这个主题开展一轮预调研，先写计划书候批。

技能会按 §〇 六步走：定元问题 → 推第一性原理 → 建首轮面板 → 跑循环 → 每站收口 → 终止判据收卷。全部产物落盘候批，不会先斩后奏。

## 方法论纪律（摘要）

预注册先于实验；一手亲取，假引用零容忍；措辞临床化（禁渲染性修辞）；只读他线辖区；风险 R1-R8 固定登记；每站收口=锚点抽验+计数快照+显式 pathspec 提交。全文见 [SKILL.md §八](SKILL.md)。
